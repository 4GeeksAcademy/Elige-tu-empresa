# Tareas — Gestor de inventario

- **Versión:** 1.0 · **Deriva de:** spec v1.0 y plan v1.0

Cada tarea tiene un commit propio, con `Checklist: T-NN (INV-…)` y el ámbito `inventory` (§5 del encargo). Los tests llevan el ID del criterio en su nombre.

**Archivos de pruebas** (en `services/api/tests/`, plan §8): `test_inventory.py` (T-01 a T-21), `test_inventoryseed.py` (T-22 a T-24) y `test_inventoryapi.py` (T-25 a T-29). Los tests «Sql» insertan filas directamente sobre una base `:memory:` para comprobar el esquema, sin pasar por los casos de uso.
